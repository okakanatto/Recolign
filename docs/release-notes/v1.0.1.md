## 直したこと

- 特定の形のファイルを選ぶと、ファイル選択画面の読み込みが何分も終わらないことがありました。1つのレコードに、引用符で囲んだ改行を含む値がとても多くある場合です。すぐに終わるようにしました。
- 書き出し先と同じフォルダに「書き出し先の名前.part」というファイルがあると、それが比べているファイルでも上書きしていました。書き出しの途中のファイルは、まだ使われていない名前で作るようにしました。
- 大きさのわりに行の数がとても多いファイルで、メモリが足りなくなると、アプリが何も示さずに終わることがありました。理由を示して止めるようにしました。比べる前のメモリの見積もりも、ファイルの先頭だけでなく全体から行の数を見積もるようにしました。
- Shift_JIS（Windows-31J）で CSV に書き出すとき、「¥」（U+00A5）「‾」（U+203E）「−」（U+2212）を、知らせずに「\」「~」「－」に変えて書いていました。ほかの表せない文字と同じく、場所を示して止めるようにしました。
- キーの値の重複を知らせるとき、とても長いキーの値をそのまま出して、画面が長く固まることがありました。長い値は先頭だけを出します。
- 変わった列がとても多いレコードの書き出しを速くしました。
- 次の設定を、exe と同じフォルダの設定ファイルではなく、ユーザーのフォルダに保存するようにしました。exe を共有フォルダに置いたとき、ほかの人が設定を変えると、自分の設定まで変わっていたためです。
  - 最近の比較を記録する
  - コピーした内容をクリップボードの履歴と同期に残さない
  - 式として読まれる値の先頭に「'」を付ける

  以前の版で exe の隣に保存した値は、データを守る側の値（記録しない、履歴に残さない、「'」を付ける）だけを引き継ぎます。
- 不具合を記録するときなどに使う Windows の部品（DLL）も、Windows のシステムフォルダからだけ読み込むようにしました。exe と同じフォルダに同じ名前のファイルを置かれても使いません。
- 使っている部品（Tauri など）を最新の版にしました。
