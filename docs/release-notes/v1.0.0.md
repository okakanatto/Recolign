2つの表のファイル（CSV、TSV、固定長のテキストなど）を、キーの列でレコードどうしを対応させて比べ、どの値が変わったか、どのレコードが片方にしかないかを確かめるWindowsアプリです。最初の版です。

## できること

- 行の順番や列の順番が違うファイルどうしを、キー（社員番号など、複数の列の組み合わせも可）で対応させて比べます。値は書き換えずに、文字どおりに比べます。
- 差分を「変更」「左のみ」「右のみ」「一致」に分け、左右の表に元の値のまま並べます。変わったセルと、セルの中で変わった文字を示します。
- 読み込める形式：区切り（カンマ、タブ、セミコロン、縦線、任意の1文字）、引用符を使わないファイル、固定長（バイト数・文字数）。文字コードはUTF-8（BOMの有無）、Shift_JIS（Windows-31J）、UTF-16、EUC-JP。左右で違っていてもかまいません。
- 文字コード・区切り・1行目が列名かどうか・キーを、ファイルの中身から推定します。キーの値の重複や空の値は、比べる前にその場所を示します。
- 同じような変更のまとめ（変更パターン）、確認済み・要調査の印とメモ（使うときだけオンにします）。
- 検索、キーの値や行番号での移動、コピー、Excel形式（差分に色付き）とCSVへの書き出し。
- Excelと同じキー操作（Ctrl+矢印、Shift+Space、Ctrl+Spaceなど）。一覧は比較画面でF1を押すと表示されます。

## 動作環境

- Windows 10／11（64ビット）
- Microsoft Edge WebView2ランタイム（Windows 10／11に標準で入っています）

インストールは要りません。`Recolign.exe` をダウンロードして実行します。初めて開くとWindowsの警告（SmartScreen）が出ることがあります。そのときは「詳細情報」→「実行」を選びます。

## データの扱い

- 比べるファイルは読むだけで、書き換えません。
- データを外部へ送りません。アプリには外部と通信する部品がなく、画面の表示部品（WebView2）の裏の通信も止めています。
- 保存するのは、画面の設定、最近の比較（記録をやめられます）、確認状況とメモ（使うときだけ）です。保存先は操作説明（`MANUAL.md`）にあります。
