# Recolign 操作説明

2つの表のファイル（CSV、TSV、固定長のテキストなど）を、指定した列（キー）でレコードどうしを対応させて比べ、どの値が変わったか・どのレコードが増えた／減ったかを確かめるアプリです。比べるファイルは読むだけで、書き換えません。データを外部へ送ることもありません。

キー操作の一覧は、比較画面で **F1** を押すと表示されます。

## 1. 起動する

- `Recolign.exe` を実行します。インストールは要りません。exeをコピーするだけで、ほかのPCでも使えます。
- Windows 10／11に標準で入っている「WebView2ランタイム」を使います。入っていないPCでは、起動時にその旨を表示します。
- ダウンロードしたexeを初めて開くと、Windowsの警告（SmartScreen）が出ることがあります。そのときは「詳細情報」→「実行」を選びます。

## 2. 比べるファイルを選ぶ

1. 左（比較元）と右（比較先）で、それぞれ「ファイルを選ぶ」を押します。ファイルをウィンドウにドラッグしても選べます（2つまとめて落とすと、左・右の順に入ります）。選んだファイルは、カードの右上の「×」で外せます。
2. 先頭の部分が表示されます。文字コード・区切り・1行目が列名かどうかは、ファイルの中身から自動で選ばれます。表示が崩れているときは、ここで直します（下の「読み込みの設定」）。
3. 「キー」で、レコードを対応させる列を確かめます（社員番号など）。値がすべて埋まっていて重複しない列を自動で選び、見出しに「キー（推定）」と出ます。違うときは、ほかの列を押して選び直します。複数の列を組み合わせることもできます。
4. 必要なら「比較の設定」を開き、比べない列（更新日時など）や、値の前後の空白を無視するかを選びます。
5. 「比較する」（Ctrl+Enter）を押します。

- エクスプローラーで2つのファイルを選んで `Recolign.exe` のアイコンに重ねて離す（または「送る」に登録して使う）と、その2つを選んだ状態で起動します。
- 前に比べたファイルは、画面の「最近の比較」から1回で選び直せます（「設定」で記録をやめられます）。
- ファイルが大きくメモリが足りなさそうなときは、比べる前に必要な量と空きを表示します。
- キーの値が重複している、空のレコードがある、列名が空か重複している、といったときは、比べる前にその場所（行番号・列）を表示し、「比較する」を押せなくします。ファイルの先頭で見つからず、比べ始めてから分かったときは、理由・場所・直し方を表示します。「条件を変更する」で戻って直します。

### 読み込みの設定

ファイルごとに選びます。左右で違っていてもかまいません（たとえば左がCSV、右が固定長）。値どうしを比べます。

| 項目 | 選べるもの |
|---|---|
| 文字コード | UTF-8（BOMの有無はどちらでも）、Shift_JIS（Windows-31J）、UTF-16 LE／BE（Excelの「Unicode テキスト」）、EUC-JP |
| 区切り | カンマ、タブ、セミコロン、縦線（\|）、ほかの文字（半角1文字を入力）、固定長 |
| 引用符（"）を使う | ふつうはオンです。「"」で囲んだ値の中の区切り文字や改行を、値の一部として読みます。データベースから出したタブ区切りのファイルなど、引用符を使わないファイルではオフにします（オンでは読めないファイルなら、自動でオフを選びます）。 |
| 1行目は列名 | 外すと、列名を「列1」「列2」…とし、左右の同じ位置の列どうしを比べます。1行目がデータの行に見えるファイルでは、自動で外れます。 |

固定長（区切り文字がなく、列ごとに桁数が決まっているファイル）は、区切りで「固定長」を選び、列の幅を左の列から順にカンマで区切って入力します（例：4, 10, 8）。

- 幅の単位は「バイト」か「文字」です。Shift_JISとEUC-JPのファイルでは、全角文字は2バイトと数えます。ファイルの仕様書の桁数がバイト数なら「バイト」を選びます。
- 「前後の空白を除く」がオンのときは、桁をそろえるための空白（半角・全角）を値に含めません。
- 幅を入力すると、ファイルの先頭の行に区切る位置を縦線で表示します。ずれていないかを確かめてから比べます。
- 幅の合計より長い行や、全角文字の途中で区切れてしまう行があるときは、その行番号を表示して止まります。
- 入力した幅や区切り文字が使えないとき（数でない、「"」など）は、その欄が赤い枠になり、下に理由が出ます。直すまで比較できません。

Shift_JISとEUC-JPのファイルの「～」は、Windowsでの読み方（全角チルダ U+FF5E）で読みます。ほかのツールでUTF-8に変換したファイルでは「〜」（波ダッシュ U+301C）になっていることがあり、文字コードの違うファイルどうしを比べると、見た目の似た別の文字として変更に数えられます。「∥」「－」「￠」「￡」「￢」も同じです。

## 3. 比較画面の見方

左右に、2つのファイルの値がそのまま並びます。行の左端の記号と色が、差の種類を表します。

| 記号 | 意味 | 色 |
|---|---|---|
| ~ | 変更（キーが同じで、値が違う） | 違う値のセルが黄色 |
| < | 左のみ（左のファイルにだけある） | 赤 |
| > | 右のみ（右のファイルにだけある） | 緑 |
| = | 一致 | 色なし |

- ツールバーの「~ 変更 12」「< 左のみ 3」などの件数を押すと、その種類の行だけを表示します。「全行」「差分のみ」でも切り替えられます。
- 「キー整列」は、同じキーのレコードを左右同じ高さに並べます。「元ファイル順」は、それぞれのファイルの行の順に並べます。行番号はどちらでもファイルの行番号です。
- 行を選ぶと、下の詳細欄に、変わった列と、文字単位でどこが変わったかを表示します。「元の行」では、ファイルに書かれているとおりの文字を見られます。
- 「左右」「上下」で、表の並べ方を切り替えます。

## 4. よく使う操作

| したいこと | 操作 |
|---|---|
| 次の差分・前の差分へ | 「次の差分」「前の差分」、または J ／ K |
| Excelと同じキーで移動・選択 | Ctrl+矢印で値が続く範囲の端へ（空のセルでは次の値へ）、Ctrl+Shift+矢印で端まで選ぶ、Shift+Spaceで行を選ぶ、Ctrl+Spaceで列を選ぶ、Ctrl+Home ／ Ctrl+Endで最初 ／ 最後のセルへ、Enter ／ Shift+Enterで下 ／ 上へ。左右の表はCtrl+PageUp ／ Ctrl+PageDownで切り替える |
| 文字で探す | 検索欄（Ctrl+F）に入力して Enter。「絞り込む」で、その文字を含む行だけを表示 |
| キーの値や行番号で移動 | 「移動」（Ctrl+G） |
| コピー | セルをドラッグまたはShift＋クリックで選んで Ctrl+C。列名も付けるときは Ctrl+Shift+C。行番号を押すと行を、列名を押すと列を、表の左上を押すと全体を選択。列を選んだときと全体を選んだときは、列名も付く |
| ファイルに書き出す | 「書き出す」→ Excel（差分に色を付ける）またはCSV（UTF-8／Shift_JIS）を選び、「保存先を選んで書き出す」 |
| 列を選ぶ・並べ替える | 列名を押すと、その列を選びます（Shift＋クリックで、そこまでの列）。並べ替えは、列名を右クリック →「昇順で並べ替え」「降順で並べ替え」 |
| 列を隠す | 列名を右クリック →「この列を隠す」。隠しても差分の判定は変わりません |
| 拡大・縮小 | Ctrl＋ホイール、Ctrl＋プラス／マイナス、Ctrl+0で100% |

## 5. 確認状況とメモ（使うときだけ）

差分を1件ずつ、またはまとめて「確認済み」「要調査」にし、メモを残せます。既定ではオフです。

1. 比較画面の「設定」で「確認状況とメモを使う」をオンにします。表の左端に確認状況の列が出ます（✓ 確認済み、? 要調査）。
2. 差分を選んで **Space** を押すと、確認済みにして次の未確認の差分へ進みます。**3** で要調査、**1** で未確認に戻します。**M** でメモを書きます。
3. 複数の行を選んで Space を押すと、件数と内容を確かめる画面が出てから、まとめて付けます。
4. 間違えたら **Ctrl+Z** で元に戻せます（やり直しは Ctrl+Y）。
5. 付けた内容は自動で保存されます。同じファイルを同じ条件で比べ直すと、読み込まれます。ファイルの中身や比較の条件が変わったときは読み込まず、そのことを知らせます。

進み具合や「次の未確認へ」は、表の左端の細い欄（変更パターン）を押して開くサイド欄にあります。「すべて未確認に戻す…」もここにあります。

## 6. 変更パターン

表の左端の細い欄を押すと、サイド欄に、同じような変更をまとめた一覧が出ます。まとまりを押すと、その行だけを表示します。

| まとめ方 | 同じとみなす条件 |
|---|---|
| 列ごとの変更 | 1つの列で、変更前と変更後の値が同じ（例：部署 営業一課 → 営業企画課） |
| 変更列の組合せ | 変わった列の組合せが同じ（値は比べない） |
| 完全な変更 | 変わったすべての列と、その前後の値が同じ。確認状況がオンなら、まとめて確認済みにできる |

更新日時のように毎回変わる列があってまとまらないときは、「まとめに使わない列」でその列を外します。外した列の変更も、差分としてはそのまま残ります。

## 7. 保存されるもの

| もの | 場所 |
|---|---|
| 画面の設定（配置・拡大率など） | exeと同じフォルダの `Recolign.settings.json`（書けないときはユーザーのフォルダ） |
| 最近の比較 | `%APPDATA%\io.github.okakanatto.recolign\history.json` |
| 確認状況とメモ | `%APPDATA%\io.github.okakanatto.recolign\reviews\`（キーの値・状態・メモ・日時だけで、データの複製は作りません） |

- 最近の比較は「設定」→「最近の比較を記録する」を外すと、記録も消えます。
- 確認状況は、ファイル選択画面の「設定」→「保存した確認状況」の「削除…」で消せます。

## 8. 困ったとき

| 表示・状況 | 対処 |
|---|---|
| 「○行目を UTF-8 として読めません」など、文字コードのエラー | ファイル選択画面で文字コードを「Windows-31J（Shift_JIS）」に変えます（逆の場合は「UTF-8」に） |
| キーの重複・空のキーで比べられない | キーの列を見直すか、複数の列を組み合わせて、1件ずつ区別できるキーにします |
| 「メモリが足りなくなったため、比較を中止しました」 | ほかのアプリを閉じてから、もう一度比べます。比べるファイルと保存した確認状況は変わっていません |
| ツールバーに「確認状況を保存できません」 | 保存先のフォルダの空き容量などを確かめてから、その表示を押すと、もう一度保存します |
| Shift_JISで書き出せない文字がある | 表示された行・列の文字を確かめ、UTF-8で書き出します |
| 会社のPCで実行できない | 実行が制限されている可能性があります。システム管理者に相談してください |
